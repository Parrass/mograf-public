# Awesome Claude Motion

A curated, link-only list of notable motion graphics and videos made with Claude (Opus 5.5 / Claude Code), plus the tools, skills and guides behind them. Every entry credits its creator and links to the original post; no media is copied here. Dates and details as of 2026-10.

## Showcase

Posts are from the Opus 5.5 wave (released 2026-09-22) unless dated otherwise. "Tool" reflects what the creator or an index states; "other" means plain HTML/Canvas/SVG or an unstated pipeline. "Prompt available" means the prompt is in the post or its thread (yes), only described or offered as a guide/repo (partial), or not shared (no).

## Learning

- [claudevideo.org](https://claudevideo.org/): unofficial index of 1,200+ Opus 5.5 videos, filterable by type, with prompts where creators shared them.
- [prompt-motion.com](https://prompt-motion.com/): gallery of 500+ Opus 5.5 motion pieces with prompts and skills, curated by @p4nthera_.
- [Skillry Opus 5.5 gallery](https://skillry.dev/ai-videos/opus-5-5): originals shown next to live remakes.
- [AY Automate creator list](https://www.ayautomate.com/resources/claude-opus-5-5-motion-graphics): roundup of ~40 creators and which ones shared prompts.
- [HyperFrames introduction](https://hyperframes.heygen.com/introduction) and [quickstart](https://hyperframes.heygen.com/quickstart): official docs; the [playground](https://hyperframes.dev) runs compositions in the browser.
- [HeyGen HyperFrames launch post (2026-04)](https://x.com/heygen/status/2044827454460871072): the launch video itself was built in Claude Code with HyperFrames.
- [Remotion Agent Skills docs](https://www.remotion.dev/docs/ai/skills) and [Claude Code plugin](https://remotion.dev/docs/ai/claude-code-plugin): official setup for Remotion with agents.
- [Remotion prompt showcase](https://www.remotion.dev/prompts): community prompts with their rendered results.
- [Tella: Remotion Agent Skills with Claude Code](https://www.tella.com/blog/how-to-use-remotion-agent-skills-with-claude-code): step-by-step setup walkthrough.
- [Nate Herk: Opus 5.5 + HyperFrames editing workflow (YouTube)](https://youtube.com/watch?v=7jHXoPGnA4c), summarised in [this write-up](https://openclawdatabase.com/news/videos/2026-09-25-opus-55-hyperframes-video-editing-workflow/): five-step agent editing loop.
- [I Built This Entire Launch Video With Claude Code + HyperFrames (YouTube)](https://www.youtube.com/watch?v=LIM3P4rWG2U): end-to-end launch-video build.
- [nocode.mba: HyperFrames + Codex launch videos](https://www.nocode.mba/articles/hyperframes-codex-launch-videos): the same approach with another agent.
- [Capital & Compute: best Claude motion tools, free and paid](https://capitalandcompute.net/blog/claude-motion-graphics-tools/): compares render engines by license and output.
- [Pasquale Pillitteri: how Opus 5.5 makes motion videos](https://pasqualepillitteri.it/en/news/19007/opus-5-5-motion-design-video-en): explains the code-to-frames pipeline and the limits of "one-shot" claims.
- [laozhang.ai: Opus 5.5 video generation](https://blog.laozhang.ai/en/posts/claude-opus-5-5-video-generation): code in, MP4 out, with known limitations.
- [Charlie Hills: Claude Code motion graphics](https://charliehills.substack.com/p/claude-code-motion-graphics): newsletter guide accompanying his free skills.
- [Moe Lueker: HyperFrames + HeyGen video skill](https://moelueker.com/blog/claude-skill-that-makes-videos-hyperframes-heygen): how a product-video skill is structured.
- [@MakeAI_CEO HyperFrames tutorial (2026-07)](https://x.com/MakeAI_CEO/status/2081253131996872764): Japanese-language tutorial, heavily bookmarked.
- [Emil Kowalski: building an animation course](https://emilkowal.ski/ui/building-an-animation-course): background on motion craft and his course.
- [GSAP docs](https://gsap.com/docs/v3/): reference for the timeline API most HTML pieces rely on.
